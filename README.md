# Mancuria Automotive Services - Customer Portal 🌐🚗
El portal web de Mancuria es una solución de cara al cliente integrada en el ecosistema SIGA-IA. Esta plataforma permite la transparencia total entre el taller y el cliente final, proporcionando herramientas de consulta en tiempo real sobre el estado de reparación y mantenimiento de vehículos en Chincha, Perú.

## 💎 Valor Agregado
A diferencia de una web informativa estática, este portal actúa como un puente de datos que consulta directamente la infraestructura de Firebase Firestore, permitiendo que el cliente reduzca la incertidumbre mediante la visualización inmediata de su Orden de Trabajo (OT).

## 🛠️ Especificaciones Técnicas
1. Motor de Consulta en Tiempo Real
Buscador de OT: Implementación de consultas asíncronas para recuperar estados de vehículos (Diagnóstico, En Proceso, Finalizado).
Validación de Identidad Vehicular: Algoritmos de filtrado para asegurar que los ingresos de placa cumplan con la normativa peruana vigente.
2. Infraestructura y Despliegue
Arquitectura Serverless: Alojado en Firebase Hosting para garantizar tiempos de carga menores a 2 segundos y disponibilidad del 99.9%.
Optimización de Activos: Estructura de archivos minificada y organizada en un directorio /public para mejorar el SEO y el rendimiento en conexiones móviles (4G/5G).
3. Diseño e Identidad Visual
UI Responsiva: Desarrollo Mobile-First para asegurar que los clientes puedan consultar su estado desde cualquier smartphone.
Branding Automotriz: Interfaz diseñada con la paleta de colores corporativa (Mancuria Red) y tipografías que reflejan precisión técnica y profesionalismo.

## 🚀 Stack de Tecnologías
- Frontend: HTML5, CSS3 Avanzado (Flexbox/Grid), JavaScript Moderno.
- Backend as a Service (BaaS): Firebase Hosting & Google Cloud Firestore.
- Gestión de Versiones: Git & GitHub para CI/CD manual.
